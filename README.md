# 📌 About The Project

**Project Vibranium** is a single-page, scroll-driven hackathon website built around a futuristic **Vibranium + Wakanda-inspired visual system**.

Instead of following a traditional college-event website layout, I focused on creating a more cinematic experience using:

- Dark futuristic visuals
- Wakandan-inspired geometry
- Vibranium-inspired energy effects
- Purple and teal lighting
- Cinematic transitions
- Interactive typography
- Custom cursor interactions
- Scroll-based storytelling
- Micro-interactions
- Responsive layouts

The overall design direction follows three priorities:

**70% — Futuristic technology & hackathon**  
**20% — Wakandan / Black Panther inspiration**  
**10% — Cinematic Marvel atmosphere**

The intention was to make the website feel like a **real event experience rather than a college assignment.**

---

# 🎯 Task Requirements

The recruiter brief required a Marvel-themed event landing page with:

- Marvel-inspired visual identity
- Cinematic hero section
- Event information and highlights
- Interactive elements and animations
- Registration / CTA
- Responsive design
- Consistent typography, spacing and colors
- Strong visual hierarchy
- Complete frontend execution

The project was designed around these requirements while keeping the implementation focused on the frontend.

ABOUT PROJECT VIBRANIUM

The mission: a 48-hour mega hackathon, run like a command center.

Project Vibranium is GeeksforGeeks Bennett University's flagship hackathon — one continuous 48-hour window where teams build, ship and defend a working solution.

FORMAT48-HOUR MEGA HACKATHON
MODETEAM-BASED
FOCUSBUILD · CODE · SHIP

Every team gets the same clock and the same arena. What separates the field is how well you build, how fast you iterate with your teammates, and how clearly you present at the end.
